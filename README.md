
# 🎯 Jogo de Adivinhação

Meu primeiro projeto desenvolvido utilizando HTML, CSS e JavaScript.

## 📌 Sobre o projeto

Um jogo simples onde o usuário precisa descobrir um número aleatório escolhido pelo computador entre 1 e 100.

## 🚀 Funcionalidades

- Geração de número aleatório.
- Verificação dos palpites.
- Dicas para encontrar o número secreto.
- Contador de tentativas.
- Reiniciar a partida.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎮 Como jogar

1. Digite um número entre 1 e 100.
2. Clique em Tentar.
3. Siga as dicas para descobrir o número.
4. Continue até acertar!
